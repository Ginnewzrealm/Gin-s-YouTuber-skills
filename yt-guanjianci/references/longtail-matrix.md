# 长尾词扩展方法论（四维算子矩阵）

> 来源：中文 SEO 运营社区成文 SOP（2026-09 调研归档）。

## 核心公式

```
长尾关键词 = 实体词根 + 四维算子（A/B/C/D 任选一）
```

| 维 | 算子类型 | 模板 | 示例 |
|---|---|---|---|
| A | 商业动作/结局 | [公司/大佬] + [破产/倒闭/暴雷/跌落神坛/收购/血亏] | 英特尔+跌落神坛、软银+暴雷 |
| B | 人/机构冲突 | [A] + VS + [B] + [战争/商战/背叛/背刺] | 英特尔 VS AMD 商战 |
| C | 疑问与归因 | 为什么 + [公司/事件] + [会失败/真相/幕后局中局] | 为什么诺基亚会失败 |
| D | 时代/时间 | [事件/年份] + [商业变局/泡沫/危机] | 日本失去的三十年 商业史 |

## 中文特有规则

| 词类 | 规则 |
|---|---|
| 错别字/同音词（孙正意） | ❌ 不进标题；✅ 进 Tags + 字幕 SRT（吃语音输入误搜流量） |
| 拼音/缩写（B站） | ✅ 括号双收录：标题用「B站（哔哩哔哩）」 |
| 口语情绪词（惨败/被坑惨了/大暴雷） | ✅ 全量收录——搜索量低但 CTR 高，是标题钩子词核心素材 |

## 机械扩展步骤

1. 从选题实体出发，先跑 A/B/C/D 四维各生成 2-3 条候选长尾
2. 按 keyword-grading.md 四级标准分级
3. 新频道优先取 小词/微长尾 且 KD<20 者进入标题候选池
