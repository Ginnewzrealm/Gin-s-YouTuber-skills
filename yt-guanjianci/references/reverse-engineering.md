# 竞品逆向方法论（Outlier 系数 + 三元拆解 SOP）

> 来源：蝉妈妈AI/视频爆点拆解框架（2026-09 调研归档）。
> 机械抓数备注：批量抓竞品播放量用 YouTube Data API v3 的
> `channels(1 quota) → playlistItems(1/页) → videos(1/50个)` 组合拳——**严禁 search.list（100 quota/次）**。
> 约 21 quota 抓 500 视频。当前账号未注册 → 走手工贴数降级（C 档）。

## 一、样本选择

- 单频道抽样 20-30 个视频（剔除 Shorts）
- **爆款系数 Outlier Score = 该视频播放量 / 频道近 10 期中位播放量**
  - ≥2.5 → 爆款样本（进拆解库）
  - 0.8–2.5 → 常规（不归纳）
  - <0.8 → 失败样本（进避坑库）

## 二、三元拆解模板

```
标题 = 【钩子词 Hook】+【句式 Syntax】+【实体词 Entity】
```

拆解范例：

| 原始标题 | 钩子词 | 句式 | 实体词 |
|---|---|---|---|
| 烧光500亿！芯片巨头一夜清零，创始人揭开幕后资本杀局 | 烧光500亿/一夜清零/资本杀局 | 数字强刺激+结局反转+揭秘幕后 | 芯片巨头/创始人 |
| 为什么明明天天爆满，暴雪却彻底搞砸了中国市场？ | 天天爆满 vs 彻底搞砸 | 为什么明明[高光]却[惨败]？ | 暴雪/中国市场 |
| 巨亏130亿！孙正义生涯最大败仗 | 巨亏130亿/生涯最大败仗 | 大额数据+个人最高级负面 | 孙正义/WeWork |

## 三、四步生成 SOP

1. **提取实体**：本期选题实体（如"波音"）
2. **匹配句式**：拆解库中找 Outlier>3.0 的句式（如"为什么明明[高光]却[惨败]？"）
3. **注入钩子**：本期最有冲击力的数据/细节（如"737 MAX 连续空难"）
4. **组合 ≥3 候选**：按 title-formulas.md 机械规范自检后产出

## 四、归纳进库

每条拆解追加到 `频道词库.json` 的 `句式库`（带 Outlier 分数与来源频道），
供下期直接匹配——**库的进化靠验证记录回流**（fupan 传 CTR 后加权）。
