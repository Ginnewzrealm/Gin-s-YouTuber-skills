# 四模块三轨工程模板（20-30 分钟深度版）

> 用户提供的权威模板（2026-09-09 第三十轮拍板）。时长只保留 20-30 分钟一档：
> 总字数目标 5600-8400 字（280 字/分 ±10%），子节点 6-8 个。
> 三轨 = 听觉轨（台词/音效/BGM/关键词）｜视觉轨（景别/运镜/客观动作画面）｜控制轨（情绪/节奏/拍点工程备注）。

## 二、四模块骨架

### 第一模块：黄金 Hook 与价值承诺（约 0:00-1:00）

目标：解决前 15 秒流失。**前 100 字必须 100% 呼应封面悬念 + 给出 1 个具体价值承诺**（定义 A1）。

```
00:00-00:05  【听觉】直奔主题：反常识观点/最强痛点，严禁废话；音效配重音冲击
             【视觉】特写/极速推进；只写客观动作（例：主讲人将文件摔在桌上，画面切黑白）
             【控制】语速极快，1 秒 1 切
00:05-00:15  【听觉】呼应封面承诺，明确本期解决什么问题；BGM 切入节奏感强的音乐
             【视觉】快速切换 3 个痛点对应素材，红框标注
             【控制】视听比 1:10，视觉密集打断
00:15-01:00  【听觉】抛出核心悬念（不剧透答案）；预告四模块交付路径
             【控制】铺垫不超过 1 分钟——20-30 分钟片的前置占比上限 5%
```

### 第二模块：主体推进与模块化交付（约 1:00-24:00，6-8 个子节点）

目标：解决逻辑散漫与中途流失。每个子节点 = 一个核心观点/步骤，**层层递进**。

```
[子节点模板]
MM:SS-MM:SS  【听觉】口语化短句讲清本节点信息点（每句 <20 字）；自然植入 SEO 关键词
             【视觉】景别 + 客观动作画面描述；B-roll 遮盖 Talking Head
             【控制】情绪标注；拍点打断位置；本节点字数配额

节奏硬规则：
- 每 2-3 分钟一个留存拍点（rehook：悬念重申/反转预告/能量切换）
- 每分钟 2-4 次 pattern interrupt；连续 Talking Head 禁超 45 秒
- 次好点放第一、最强点放第二（价值递增曲线）
```

子节点字数配额（按 7000 字中值拆）：Hook 模块 ~250 字；每个子节点 ~700-900 字；高潮 ~600 字；CTA ~150 字。

### 第三模块：高潮与终极价值交付（约 24:00-27:00）

目标：情绪共鸣最高点 + 互动引导。解答 Hook 悬念的最强干货在此交付。

```
【听觉】给出最强结论，语速放缓，情绪饱满；BGM 推向高潮或瞬间静音（Mob Drop）
【视觉】大特写；主讲人直视镜头，背景灯光微暗
【控制】情绪唤醒最高点；引导评论区留言（具体问题，非"欢迎讨论"）
```

### 第四模块：无缝跳转 CTA（约 27:00-28:00，3 秒内收束）

目标：完播率断崖防护 + 连续观看。

```
【听觉】"……所以核心就是这三点。而如果你想进一步知道具体落地工具，
        点我旁边的这期视频，我们接着聊。"
        绝对禁止："以上就是本期全部内容" / "喜欢请点赞" / "我们下期再见"
【视觉】说到"这期视频"时手指向屏幕侧方，同侧弹出 End Screen 推荐卡片
【控制】不给观众"视频要结束了"的时间窗口，直接拉高频道完播率
```

## 三、三轨正文格式（每段统一结构）

停顿/重音符号体系（配音照读即可）：`,` = 停 0.5 秒　`/` = 停 1 秒　`·` = 重音。
可砍级：🟢 必保（删了故事断）　🟡 可压缩（删 30% 不影响主线）　🔴 可删（整块拿掉不影响理解）。

```script
## [MM:SS-MM:SS] 子节点 N：<名称> [可砍级：🟢]
【听觉】[台词]："逐字稿，单句≤20字，带停顿/重音符号"
        [音效/BGM]：[名称或"无"]
        [关键词]：[本段植入的 SEO 词，或"无"]
【视觉】[景别/运镜]：[中景/特写/推进...|~N秒]
        [画面描述]：客观物理动作，禁抽象形容词
        [B-Roll]：[BR-编号，链接 B-Roll 清单]
【控制】[情绪]：[平稳/紧张/高涨...|段位L1-L4]
        [拍点]：[本段 rehook 位置与方式；或"次级悬念"标记]
        [凭证]：[画面/事实的公开凭证编号——铁律 2，禁空]
```
