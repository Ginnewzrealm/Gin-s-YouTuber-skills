# 四模块三轨工程模板（20-30 分钟深度版）v0.3

> 用户提供的权威模板（2026-09-09 第三十轮拍板，v0.2 并入故事主线标准；v0.3 主线换轴英雄之旅+CTA 两触点）。
> 时长只保留 20-30 分钟一档：A 稿（纯口播）总字数 5600-8400 字（280 字/分 ±10%）。
> 本频道定位：**讲商业故事**——主线铁律见 writing-playbook.md §一（切入瞬间→拉回原点→关卡流→现状+未来）。
> 三轨 = 听觉轨（台词/音效/BGM/关键词）｜视觉轨（景别/运镜/客观动作画面）｜控制轨（情绪/节奏/拍点/内容层标注）。
> 交付 = **A 稿（纯口播故事稿，主产物）+ B 稿（三轨视听制作本，从 A 稿派生）**双轨制。

## 二、四模块 × 四幕骨架

四模块是交付结构，四幕是故事结构，映射如下（24 分钟版；其他时长按占比 12.5/25/37.5/25 伸缩）：

| 四幕 | 时长 | 落在哪个模块 |
|------|------|-------------|
| 第一幕·切入瞬间 | 0-3min | 第一模块全部 + 第二模块前段 |
| 第二幕·拉回原点 | 3-9min | 第二模块中段 |
| 第三幕·关卡流（3-5 关） | 9-18min | 第二模块后段（关间因果桥梁句） |
| 第四幕·现状+未来 | 18-24min | 第三模块 + 第四模块 |

### 第一模块：黄金 Hook 与价值承诺（约 0:00-1:00）

目标：解决前 15 秒流失。**前 100 字必须 100% 呼应封面悬念 + 给出 1 个具体价值承诺**（定义 A1）。

```
00:00-00:05  【听觉】故事直入：切入瞬间第一视角（轰鸣/大火/救人动作），严禁废话；音效配重音冲击
             【视觉】特写/极速推进；只写客观动作（例：起火瞬间赛车被黑烟吞没，红框圈定 91 号车号）
             【控制】语速极快，1 秒 1 切
00:05-00:15  【听觉】反差落下（英雄 49 秒 vs 救护车 15 分钟），建立核心悬念
             【视觉】快速切换 3 个痛点对应素材，红框标注
             【控制】视听比 1:10，视觉密集打断
00:15-01:00  【听觉】抛出核心谜团（给结果不给原因），预告故事路径；禁报股票代码/股权/财报
             【控制】铺垫不超过 1 分钟——20-30 分钟片的前置占比上限 5%
```

**切入瞬间硬规则**：开场 3 分钟内严禁股票代码/股权占比/财报术语（机器硬扫）；观众未对"人的命运"产生共鸣前，禁止拽进金钱逻辑。

### 第二模块：主体推进（约 1:00-21:00，5-8 个子节点，按四幕分幕）

目标：解决逻辑散漫与中途流失。每个子节点 = 故事的一个推进节拍（不是"一个观点/步骤"），**幕幕递进**。关卡流段每个子节点 = 一关，按四拍写：挑战 vs 信念 → 抉择 → 代价 → 暂时结果。

```
[子节点模板]
MM:SS-MM:SS  【听觉】口语化短句推进剧情（每句 <20 字）；自然植入 SEO 关键词
             【视觉】景别 + 客观动作画面描述；B-roll 遮盖 Talking Head
             【控制】情绪标注；拍点打断位置；[内容层]标注；本节点字数配额

节奏硬规则：
- 每 2-3 分钟一个留存拍点（rehook：悬念重申/反转预告/能量切换）
- 每分钟 2-4 次 pattern interrupt；连续 Talking Head 禁超 45 秒
- 拉回原点→关卡流之间架因果桥梁句（"为什么千万级的赛事，安保会坍塌成这样？
  答案不在赛道上，而在幕后运营方的账本里"）
```

子节点字数配额（按 7000 字中值拆）：Hook 模块 ~250 字；拉回原点子节点合计 ~1700 字；关卡流各关合计 ~2600 字；现状+未来（高潮+CTA）~1800 字。

### 第三模块：高潮与终极价值交付（约 21:00-23:30）

目标：情绪共鸣最高点 + 买前认知落地（不是事实汇总）。解答 Hook 悬念的最强洞察在此交付。

```
【听觉】给出最强结论（观点层金句），语速放缓，情绪饱满；BGM 推向高潮或瞬间静音（Mob Drop）
【视觉】大特写；主讲人直视镜头，背景灯光微暗
【控制】情绪唤醒最高点；[内容层]：观点——金句必须带论证链（由哪几关事实推出）
【铁禁】只罗列法条/声明=说明文，退回重写
```

### 第四模块：CTA 两触点（约 23:30-24:00，3 秒内收束）

目标：完播率断崖防护 + 连续观看 + 轻互动。**两触点制（2026-09-10 拍板）：尾屏推荐视频 + 一句点赞关注；砍掉片中卡片（iCard）。**

```
【听觉】"……所以核心就是这三点。如果这个拆解对你有用，点个赞。
        而如果你想进一步知道具体落地工具，点我旁边的这期视频，我们接着聊。"
        绝对禁止："以上就是本期全部内容" / "我们下期再见" / 点赞评论订阅三件套连念
【视觉】说到"这期视频"时手指向屏幕侧方，同侧弹出 End Screen 推荐卡片
【控制】不给观众"视频要结束了"的时间窗口，直接拉高频道完播率
```

## 三、双轨正文格式

### 文件 A：纯口播稿（主产物，先写）

- 只有故事文本 + **黑体金句**（锚定抉择），无任何画面代码/股票代码裸报/技术参数
- 四幕标题分节（切入瞬间/拉回原点/关卡流/现状+未来），每幕尾 1 句黑体锚定抉择（"他放弃了什么、赌了什么"）
- 口播念法即文字本身：英文人名首次出现念"中文译名（英文原名）"，之后中文简称
- 用途：审核台词感与情绪流；WPM/单句长度/金句/人名/开场财报闸全部跑在 A 稿上

### 文件 B：三轨视听制作本（从 A 稿派生，后写）

停顿/重音符号体系（配音照读即可）：`,` = 停 0.5 秒　`/` = 停 1 秒　`·` = 重音。
可砍级：🟢 必保（删了故事断）　🟡 可压缩（删 30% 不影响主线）　🔴 可删（整块拿掉不影响理解）。

```script
## [MM:SS-MM:SS] 子节点 N：<名称> [可砍级：🟢]
【听觉】[台词]："逐字稿，单句≤20字，带停顿/重音符号"
        [音效/BGM]：[名称或"无"]
        [关键词]：[本段植入的 SEO 词，或"无"]
【视觉】[景别/运镜]：[中景/特写/推进...|~N秒]
        [画面描述]：客观物理动作，禁抽象形容词
        [B-Roll]：[BR-编号，链接 B-Roll 清单]
【控制】[内容层]：[事实-多方 / 事实-单源 / 争议 / 转述-归属方 / 观点]
        [情绪]：[平稳/紧张/高涨...|段位L1-L4]
        [拍点]：[本段 rehook 位置与方式；或"次级悬念"标记]
        [凭证]：[画面/事实的公开凭证编号——铁律 2，禁空]
```

**双语人名规范（A/B 稿同规则）**：全文英文人名首次出现必须"中文译名（英文原名）"
（如：卢克·哈托格（Loek Hartog）、罗曼·格罗斯让（Romain Grosjean）），后续统一中文简称。

**四层内容标注（HR-8，详见 quality-hardrules.md）**：
事实-多方 / 事实-单源（台词必带"据X反映/疑似"限定）/ 争议（未决时 A 稿双向呈现+悬置）/
转述-归属方 / 观点（带论证链，全片 ≥1）。A 稿靠归属话术分层，B 稿控制轨显式标注。

## 四、交付物结构

飞书 doc 单文档内含双稿；本地存档 A/B 各一文件：

```
# 【选题标题】脚本 v{版本} - {YYYYMMDD}
> 元数据头（含故事主线一句话+核心争议点）+ 软维度评分表 + 预期留存档位标注
## Part 1 原爆点筛选记录（Top3 + 落选及理由；开场候选过资格闸记录）
## Part 2 产前准备：B-Roll 素材清单（按时间轴）+ 法律口径预审结论
## Part 3a A 稿（纯口播故事稿）——四幕分节，黑体金句
## Part 3b B 稿（三轨视听制作本）
## Part 4 自检报告（scan_script.py 输出 + 软维度评分 + 三视角检查勾选）
## Part 5 待用户决策项
```

本地主档：本技能 `workspace/<编号>/script-A.md` 与 `script-B.md`（B 含完整交付物头）；交付时合并推飞书 `03-脚本.md`（+create/+overwrite）。

## 五、撰写审查清单（交人审前逐项过）

| # | 检查项 | 合格标准 | 机检 |
|---|--------|---------|------|
| 1 | 前置数据审查 | 开场 3 分钟无任何股票代码/股权占比/财报术语 | ✅ scan 硬拦 |
| 2 | 因果连线审查 | 拉回原点→关卡流有明确解谜转折句；数据只解答疑问，不展示 | 人审 |
| 3 | 数据故事化审查 | 财报数据翻译成剧情动机（禁直接念"商誉减值 1562 万"） | 人审 |
| 4 | 金句观点审查 | 四幕每幕尾有黑体锚定抉择（放弃什么/赌什么）；观点带论证链 | 半机检（A 稿零黑体警告） |
| 5 | 双语人名审查 | 英文人名首现=中文译名（英文原名），后续中文简称 | ✅ scan 警告 |
| 6 | 四层标注审查 | B 稿每段有 [内容层]；全片 [观点] ≥1 | ✅ scan 硬拦+警告 |
