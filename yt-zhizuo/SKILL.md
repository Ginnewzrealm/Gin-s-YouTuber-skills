# yt-zhizuo 制作四件套

## 概述

对**已定稿脚本**做制作前翻译：消费 yt-jiaoben 的 B 稿（听觉轨/视觉轨/控制轨/B-Roll 清单）→ 一次出齐四件施工指令 → 扫描闸过检 → 飞书单文档交付 → 回填选题表「制作四件套」字段。

核心原则：

1. **本技能是翻译层，不是创作层**——说什么（文案/观点/结构）一概不改，只回答"怎么把它做出来"。文案问题回 yt-jiaoben。
2. **零自研素材**——所有画面素材来自 jiaoben B-Roll 清单（其来源= ziliao 报告内 或 已标注"自行获取+合法途径"）；缺口报回上游补采，**本技能禁止自己上网找画面**。
3. **混合形态分开施工**——露脸段（开场/关键段）走实拍分镜（机位/景别/服装道具连续性）；无脸段走 B-Roll 素材库或 AI 生成（可灵/即梦，prompt 必填）。判定口诀：**换文案答案就变 → 归 jiaoben；与文案无关只问执行 → 归本技能。**
4. **机器扫格式与规范，人做画面取舍**——本技能无硬闸门；画面采用/舍弃由人在剪辑时定。
5. **路径不硬编码**——token/ID/目录一律读 `config.yaml`，禁止缩写。

## 何时使用 / 不适用

| 场景 | 归属 |
|---|---|
| "出制作四件套" / 脚本定稿后准备拍摄剪辑 | ✅ 本技能 |
| 四件套其中一件要修订（人反馈后） | ✅ 本技能（版本号 +1） |
| 写/改脚本内容 | ❌ yt-jiaoben |
| 实际拍摄/剪辑/配音/混音执行 | ❌ 人工与工具（剪映/CapCut 等） |
| 标题/描述/标签/缩略图等发布包装 | ❌ agrici `/youtube metadata`（上游） |

## 铁律（违反即返工）

- **禁自研素材**：素材来源只能三选一（ziliao 报告内 / 自行获取+合法途径 / AI 生成+prompt），第四来源不存在。
- **禁静默丢弃**：jiaoben B-Roll 清单逐条销号（采用/自行获取/AI 生成），弃用须在 Part 5 写明去向+原因（继承 ziliao 审计链精神）。
- **画面客观化**：写客观动作，禁"气氛紧张"类形容词（继承 jiaoben HR-5）。
- **露脸段必标机位/景别；AI 段必带完整 prompt（工具名+画面描述）**——扫描闸机械强制。
- **时间码贯穿**：四件统一 `MM:SS-MM:SS`，段号与 jiaoben B 稿一致；Part 2 合计时长 vs 成片声明 ±10% 内。
- **涉敏感主体标 [法审]**（消费 fenxi 敏感主体清单），只标雷不排雷。
- **扫描不过不交付**：`scan_briefs.py` exit 0 才准建飞书文档。

## 执行流程

### 阶段 1：输入校验

读 config.yaml（缺失→从 config.template.yaml 复制走初始化问答：池 token/文档文件夹/输出目录）。校验输入：
- yt-jiaoben 定稿 B 稿（含 B-Roll 清单）存在；缺失 → 报回 yt-jiaoben，**终止不硬跑**
- 输出目录 = core 共享配置 `dirs.briefs`（默认 `~/Documents/YouTuber工作流/制作四件套/<编号>/`）

### 阶段 2：四件生产

按 `references/briefs-template.md` 施工，要点：

1. **配音 brief**：全文标注（//停顿/粗体重音/[情绪]/<Speed>）；WHY 提示给动机不给指令（吸收 voiceover-direction 底座）；露脸段注明"出镜=口播"；录音参数=分段 2-3 分钟+手机/领夹麦；修音=Adobe Podcast 免费档。
2. **分镜+B-Roll 清单（段级 B 版）**：每段一行，五列刚性字段=形态/画面/来源/prompt/连续性。B-Roll 清单逐条销号（采用→落入某段；弃用→Part 5 记去向+原因）。AI 段写可灵/即梦中文 prompt；露脸段写机位/景别/服装道具连续性（吸收 agentara video-storyboard 规范）；B-Roll 段写素材库检索词（Pexels/Storyblocks 等，仅限 jiaoben 已标注"自行获取"项）。
3. **剪辑 brief**：节奏断点（Hook 1.5-2.5s/展开 3-5s 视觉变化）+ 字幕（思源黑体 Heavy 白字黑边中下 1/3）+ 转场 + 导出参数（Mac 剪映：MP4 H.264 4K 30fps，-14 LUFS，峰值 -1 dBFS）。
4. **配乐提示**：四阶段情绪板（悬疑 Hook/中性铺陈/冲突高潮/反思升华）+ YouTube Audio Library 英文检索词 + 音量闪避规范。曲库列留"待填"，订阅 Epidemic Sound 后仅换曲库不换结构。

### 阶段 3：扫描闸

`python3 scripts/scan_briefs.py <本地草稿.md>`：四件节头齐 / 逐镜头有源 / 时间码连续且总时长对账 ±10% / AI 带 prompt / 露脸带机位景别。exit 1 → 按清单回阶段 2 修正重扫。

### 阶段 4：交付

- 本地草稿存 `<输出目录>/<编号>-v<版本>.md`
- 飞书文档：按模板五节（Part 1~5）创建，标题白名单清洗（禁 `/\:*?"<>|`），存入 config `doc.folder_token`；创建后拿 URL
- 回填：选题表「制作四件套」字段=文档 URL（**先 `+field-list` 查字段类型**，text 类型收裸字符串；字段不存在则报人建字段）
- 汇报：四件各一行摘要 + 扫描结果 + B-Roll 销号统计 + 下一步（人做片 → agrici metadata 出上传包）

## 数据契约

| 项 | 约定 |
|---|---|
| 输入 | yt-jiaoben 定稿 B 稿 + B-Roll 清单 + fenxi 敏感主体清单 |

| 不回写 | 选题状态本技能不动（制作中状态由人维护） |

## 常见错误

| 错误 | 正确做法 |
|---|---|
| 素材不够就自己上网搜 | 报回 yt-jiaoben/yt-ziliao 补采；本技能零自研 |
| 四件写成四份独立文档 | 一份飞书文档五节；人审一处看全 |
| 画面写"气氛紧张" | 写客观动作（继承 jiaoben HR-5） |
| 把"每 3 秒切镜"当铁律写到展开段 | Hook 段才 1.5-2.5s；展开段 3-5s 且允许长镜头配 BGM 起伏 |
| 替人决定弃用某条 B-Roll 不登记 | 弃用必须 Part 5 记去向+原因（销号制） |
| 改脚本句子让画面更顺 | 文案层回 yt-jiaoben；本技能只翻译 |
| 回填字段不看类型直接塞 URL | 先 `+field-list` 查类型，text 收裸字符串 |
