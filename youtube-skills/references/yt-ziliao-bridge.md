# yt-ziliao 桥接约定

> 触发条件：路由结论指向资料采集（池状态=阶段二且资料未就绪），或被调用方需要补采时，必须先读本文件。
> 前置条件：用户环境中已安装 yt-ziliao 技能。

## 一、职责边界

调用方技能（youtube-skills）负责：
- 检测 yt-ziliao 是否已安装
- 传入选题标识与采集触发意图
- 接收交付通知（报告链接 + 完整度），回读池确认状态迁移后重新路由

被调用方技能（yt-ziliao）负责：
- 全网采集、可信度评分、六章报告、飞书文档写入、回填「资料采集」字段、manifest.json 落盘（v2.6 起）

本技能明确不执行以下操作：
- 不代替 yt-ziliao 执行任何搜索/评分/写作
- 不修改资料包内容；资料疑点只能等 fenxi 记入盲区后回采
- 不催问采集细节（平台/条数），那是 ziliao 的 micro 进度

## 二、依赖检测

检测方式：`yt_core.py skills` 子命令或 SKILL.md 存在性检查。

- 已安装 → 转交时附桥接输入参数
- 未安装 → 提醒安装 yt-ziliao；路由结论标注"采集不可用"，暂停推进

## 三、输入参数

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|---|---|---|---|---|
| topic_id | string | 是 | T-XXXX-XXX 或标题 | 采集主体 |
| record_id | string | 否 | 池记录 ID | 有则传入，免 ziliao 二次定位 |
| trigger | string | 是 | 全量采集 / 补采 | 补采时由 fenxi 经其 bridge 直调，core 只发起全量 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|---|---|---|---|
| 报告链接 | string | 完成 | 飞书文档 URL（已回填「资料采集」字段） |
| 资料完整度 | number | 完成 | 0-100 |
| manifest 路径 | string | v2.6 起 | 本地 manifest.json 路径（下游 fenxi 消费对账用） |

## 五、异常处理

| 异常情况 | 处理方式 |
|---|---|
| yt-ziliao 未安装 | 提醒安装；路由暂停，禁止 core 代采 |
| 自检未过被阻断 | 尊重阻断，待人处理；core 不跳过自检代写入 |
| 降级态（OpenCLI 不可用） | ziliao 内部按自身规则等用户确认；core 只转述状态 |
