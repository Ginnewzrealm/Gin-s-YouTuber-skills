# yt-fenxi 桥接约定

> 触发条件：路由结论指向选题分析（池状态=阶段二且资料就绪：有链接+完整度≥60），必须先读本文件。
> 前置条件：用户环境中已安装 yt-fenxi 技能；yt-ziliao 已交付资料包。

## 一、职责边界

调用方技能（youtube-skills）负责：
- 检测 yt-fenxi 是否已安装
- 传入选题标识 + 资料就绪证据（链接/完整度）
- 接收 N9 迁移结果（状态=阶段三：确认选题 / 已淘汰），回读池复核后重新路由

被调用方技能（yt-fenxi）负责：
- N2 就绪复检 → 穷举 → 核验 → C 闸门 → N8 人审拍板 → N9 状态迁移与字段回填

本技能明确不执行以下操作：
- 不参与评分/闸门/穷举的任何判断
- 不替人回答 N8 拍板（硬闸门②）
- 不改分析卡内容（卡=本地 markdown，归 fenxi 所有）

## 二、依赖检测

检测方式：`yt_core.py skills` 子命令或 SKILL.md 存在性检查。

- 已安装 → 转交，附就绪证据
- 未安装 → 提醒安装 yt-fenxi；路由暂停

## 三、输入参数

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|---|---|---|---|---|
| topic_id | string | 是 | T-XXXX-XXX 或标题 | 分析主体 |
| record_id | string | 否 | 池记录 ID | core 读池时已得，传入免二次定位 |
| 资料就绪证据 | object | 是 | {链接, 完整度} | N2 复检的输入；证据不足 fenxi 会按自身 bridge 回采 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|---|---|---|---|
| N9 结果 | string | 完成 | 做（状态=阶段三）/ 不做（状态=已淘汰）/ 改方向（回环中） |
| 分析卡路径 | string | 完成 | 本地分析卡路径（供人审与下游 jiaoben 使用） |

## 五、异常处理

| 异常情况 | 处理方式 |
|---|---|
| yt-fenxi 未安装 | 提醒安装；路由暂停 |
| N8 人审未拍板 | 阻塞态正常；core 不催不代答，等人 |
| C 闸门不通过 | 状态=已淘汰属正常终态；core 按终态渲染，不重开 |
| 补采失败 | fenxi 终止并报缺失清单；core 路由回 yt-ziliao 或待人决策 |
