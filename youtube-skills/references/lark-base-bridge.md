# lark-base 桥接约定

> 触发条件：core 需要读选题池定位选题状态（步骤 2）、或初始化时检测选题池可达性时，必须先读本文件。
> 前置条件：用户环境中已安装 lark-base 技能。

## 一、职责边界

调用方技能（youtube-skills）负责：
- 检测 lark-base 是否已安装
- 传入选题编号/标题作为查询条件
- 接收池行字段（选题状态/资料采集/资料完整度）并用于路由映射

被调用方技能（lark-base）负责：
- 飞书多维表格的全部读写、鉴权、限频、错误码

本技能明确不执行以下操作：
- 不直接调用任何飞书 API / lark-cli
- 不持有任何 lark 凭证（token 只存在于 lark-* 技能内部与本技能的用户级配置"定位符"字段）
- 不写池（状态迁移归子技能 N9 与人审，core 只读）

## 二、依赖检测

检测方式：用户环境中检查 lark-base 技能是否已安装（SKILL.md 存在性）。

- 已安装 → 告知"读池通道已就位"，继续
- 未安装 → 提醒安装 lark-base；路由流程暂停，备用通道：请用户口述该选题当前状态

## 三、输入参数

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|---|---|---|---|---|
| base_token | string | 是 | 原样全文，禁缩写 | 选题池所在 base（来源：共享配置 pool.base_token，空则现场问用户） |
| table_id | string | 是 | tbl 前缀原样全文 | 选题表 ID（来源同上） |
| topic_key | string | 是 | 选题编号（T-XXXX-XXX）或标题 | 定位用的匹配键 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|---|---|---|---|
| status | string | 始终 | success / not_found / error |
| 选题状态 | string | success | 池状态字段原值（路由映射的唯一依据） |
| 资料采集 | string | success | 资料文档链接，空=无 |
| 资料完整度 | number | success | 0-100 |
| record_id | string | success | 池记录 ID（供下游子技能复用，免二次定位） |

## 五、异常处理

| 异常情况 | 处理方式 |
|---|---|
| lark-base 未安装 | 提醒安装；备用通道=用户口述状态；禁止 core 直连飞书 |
| status = not_found | 列最接近的 2-3 个候选请人确认，禁止模糊匹配硬跑 |
| status = error | 展示错误原因；读池纪律：search/get 定位，list 必分页 ≤10，输出管道截断 |
| 选题状态为空 | 标注「未登记」，按未知状态处置，禁止猜默认阶段 |
