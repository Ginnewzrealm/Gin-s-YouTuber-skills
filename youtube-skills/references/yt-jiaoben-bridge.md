# yt-jiaoben 桥接约定

> 触发条件：路由结论指向脚本制作（池状态=阶段三：确认选题），必须先读本文件。
> 前置条件：用户环境中已安装 yt-jiaoben 技能；yt-fenxi N9 已交付分析卡（含九字段契约）。

## 一、职责边界

调用方技能（youtube-skills）负责：
- 检测 yt-jiaoben 是否已安装
- 传入选题标识 + 分析卡路径
- 接收交付结果，提醒人审硬闸门③

被调用方技能（yt-jiaoben）负责：
- 输入契约校验 → 原爆点筛选 → A 稿纯口播 → B 稿三轨 → 硬指标扫描 → 法审 → 人审

本技能明确不执行以下操作：
- 不参与故事/画面/口径的任何创作判断
- 不替人定稿（硬闸门③）
- 不改选题方向（改方向回 yt-fenxi，由 jiaoben 自身规则处理）

## 二、依赖检测

检测方式：`yt_core.py skills` 子命令或 SKILL.md 存在性检查。

- 已安装 → 转交，附分析卡路径
- 未安装 → 提醒安装 yt-jiaoben；路由暂停

## 三、输入参数

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|---|---|---|---|---|
| topic_id | string | 是 | T-XXXX-XXX 或标题 | 脚本主体 |
| record_id | string | 否 | 池记录 ID | 回填「选题脚本链接」用 |
| 分析卡路径 | string | 是 | 本地 md 路径 | N9 九字段契约的载体；缺字段 jiaoben 会走 Step 0.5 补建 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|---|---|---|---|
| 双稿产物 | string | 完成 | A 稿+B 稿交付位置（飞书 doc + 本地存档） |
| 回填状态 | string | 完成 | 「选题脚本链接」是否已回填 |

## 五、异常处理

| 异常情况 | 处理方式 |
|---|---|
| yt-jiaoben 未安装 | 提醒安装；路由暂停 |
| 输入契约缺字段 | jiaoben Step 0.5 补建找人确认；core 不代补 |
| 法审不通过 | jiaoben 退回 yt-fenxi 重评；core 按回环重新路由到 fenxi |
| 3 轮改稿仍不满意 | jiaoben 停止改稿回 fenxi 重选角度；core 路由阶段回 3 |
