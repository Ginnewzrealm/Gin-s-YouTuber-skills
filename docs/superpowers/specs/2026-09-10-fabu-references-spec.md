# yt-fabu 发布技能规格：引用来源清单（06b）+ 发布包装

> 状态：待建技能的核心交付物 spec。yt-fabu 本体未建，本文件先锁定「引用来源清单」的设计，建技能时照此实现。

## 一、定位

视频发布时的**公开引用列表**（References），面向观众/平台/未来的自己：
- 回应"你这么说有依据吗"——对冲平台 fact-check
- 与 Part 2 视频素材总表分工：素材总表（yt-jiaoben）给制作者下载用；引用来源（yt-fabu）给观众溯源用

## 二、产出物

`06b-引用来源.md`（推飞书，位置=选题文件夹内，与 06-发布包装.md 并列）：

```markdown
# 引用来源：{选题标题} T-XXXX-XXX

## 视频画面
- {标题}（{UP主/频道}）{URL}

## 图文报道
- {标题}（{媒体名}）{URL}

## 官方档案 / 书籍
- {标题}（{机构/作者}）{URL 或书目信息}
```

## 三、自动汇聚路径（不人工整理）

源头 = yt-ziliao 的 `materials.json`（全量带 URL）+ yt-jiaoben 的 Part 2 视频素材总表：

1. **视频画面**组：Part 2 总表中状态 ✅ 的行（链接已过 curl 复核）
2. **图文报道**组：materials.json 中 type ∈ {新闻报道/人物特稿/纪实报道/媒体复盘/财经报道} 且 authority ∈ {高,中}
3. **官方档案/书籍**组：type ∈ {官方批文/官方档案/人物自著/纪实文学/学术研究}，无 URL 的给书目信息

## 四、规则

1. 引用列表只收**成片实际用到**的素材——对照 Part 3b B 稿的 [凭证] 编号过滤，未上片的素材不进列表
2. 每组内按"先官方后媒体再视频"的公信力排序
3. 链接有效性复用既有 curl 复核结果，不重复验证
4. 发布时：YouTube 描述贴简版（前 10 条）+ 置顶评论/简介区全量，或按平台字符限制截断

- 建议新增字段「引用来源」URL ← 06b-引用来源.md（建技能时一并 field-create）
