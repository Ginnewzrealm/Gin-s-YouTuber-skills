# 飞书表格读写规范

## 读取规则

- **实时字段清单**：每次操作前必须获取实时字段，不依赖缓存字段名
- **搜索定位**：精确匹配 → 模糊匹配 → 列出最接近的2-3行询问用户
- **禁止凭"没看到"判断不存在**
- **元数据字段**：除 `field_read` / `field_write` 外，其他字段采用语义启发式识别为可选元数据（如切入视角、语言版本、法律风险），有则纳入决策，没有不阻塞

## 写入规则

| 场景 | 行为 |
|------|------|
| 值为空 | 直接写入 |
| 值已有数据 | 询问用户是否覆盖 |
| 重新搜集 | 覆盖旧链接，无需确认 |
| 读表失败 | 按首次写入处理，标注⚠️ |

**重新搜集的判定条件**（满足任一即可）：
1. 用户明确说「重新搜集」「再搜一次」「更新资料」
2. 用户说「这个选题的资料太旧了，重新来」

**不属于重新搜集的情况**：
- 用户只是再次触发同一选题名称，没有明确表达重新搜集意图 → 按「值已有」处理，询问是否覆盖

**禁止：静默覆盖、未经复查说"已写入"**

## 完整字段读取

读选题行时同步读取元数据（法律风险、切入视角、语言版本等），有就纳入决策，没有不阻塞。

## 全局禁止

```
❌ 禁止 create 新行
❌ 禁止静默覆盖已有数据
❌ 禁止未经复查说"已写入"
❌ 禁止硬编码字段名
```
