# 选题表字段映射（36 字段 × fenxi 使用规则）

> 数据源：飞书多维表格「选题表」（base_token 以桥接调用时传入为准，不写死在本文件）。
> 本文件是 fenxi 读写选题池的字段真源。读写一律经 lark-base 桥接，字段名以下表为准。

## 状态机（选题状态字段）

| 选项 | 含义 | fenxi 权限 |
|---|---|---|
| 阶段一：想法记录 | 入口态（新） | 只读（分析起点） |
| 想法记录 | 入口态（老选项，等价于阶段一） | 只读（分析起点） |
| 阶段二：资料研究 | 资料包采集中/就绪 | **可写**（补采完成时） |
| 阶段三：确认选题 | 人拍板立项 | **可写**（人审"做"时） |

| 已发布 | 上线 | 只读 |
| 已淘汰 | 枪毙 | **可写**（闸门不过/人审"不做"时） |

## 字段分组与 fenxi 使用规则

### A. fenxi 读写区

| 字段 | 类型 | fenxi 用法 |
|---|---|---|
| 选题状态 | select | 见状态机 |
| 有法律风险 | checkbox | C 闸门②合规结论回写：有风险=勾选；同时是既有手动习惯字段 |
| 核心钩子 | text | N9 回填（空则填、不覆盖） |
| 目标受众 | text | N9 回填（空则填、不覆盖） |
| 复盘笔记 | text | 人审"不做"时，若为空可填一行淘汰理由 |
| 资料采集 | text | N2 只读（存 ziliaocaiji 报告链接）；补采完成后由 ziliaocaiji 侧回填 |
| 资料完整度 | number(0-100) | N2 只读；≥60 为就绪线 |

### B. 只读输入区（分析原料）

| 字段 | 类型 | 用途 |
|---|---|---|
| 选题编号 | text | 分析卡文件名主键（T-2026-NNN） |
| 选题标题 | text | 主体识别 + N1 选题精化时更新 |
| 一句话描述 | text | 粗选题语义，N1 精化参照 |
| 选题分类 | select | 机评语义解析的领域上下文 |
| 标签 | multiSelect | 🔥热点/常规/长尾/系列——热点标签不免闸门（Q5） |
| 优先级 | select | 人维护；fenxi 只给建议不代写 |
| 切入视角 | select | 产品/人/事件视角；N9 回填选定角度的粗分类 |
| 语言版本 / 内容形式 / 选题类型 | select | 分析卡上下文，机评对标池过滤参数 |
| 创建日期 | datetime | 时新度参考 |

### C. 竞品区（只读，机评对标参考）

| 字段 | 类型 |
|---|---|
| 竞品有爆款 / 竞品无爆款 | checkbox |
| 竞品爆款播放量 | number |
| 竞品参考 | text |

### D. 人审 checklist 区（只读，C 闸门对照）

有戏剧张力 / 有权威信息来源 / 无一手来源 / 受众覆盖面广 / 我有热情 / 可做成系列 / 我有独特角度（均为 checkbox）——Part 2 人审打分表的字段化，fenxi 不代写，仅作分析卡"人审 checklist 对照"节的数据。

### E. 下游区（只读，越权）

选题脚本链接 / 脚本字数 / 预计时长（分钟）/ YouTube URL / 首日播放量 / 48h播放量 / 受众留存价值——阶段四及 fupan 领域的字段，fenxi 一律不碰。

## 五个拍板决定（与 SKILL.md 铁律对应）

1. 淘汰落 `选题状态=已淘汰`（选项已存在，API 添加于 2026-09-09）
2. 机评四维分**不进表**，只存分析卡
3. 穷举结果**不进表**，只存分析卡；表只留人拍板的终态
4. 合规结论复用 `有法律风险` checkbox
5. N9 回填范围 = 状态 + 核心钩子 + 目标受众（**空则填、不覆盖**）
