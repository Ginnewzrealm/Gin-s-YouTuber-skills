# lark-base 桥接约定

> 触发条件：N1 读选题行、N2 资料就绪检查、N9 状态迁移与字段回填时，必须先读本文件。
> 前置条件：用户环境中已安装 lark-base 技能（lark-cli）。

## 一、职责边界

调用方技能（xuanti-fenxi）负责：
- 检测 lark-base 是否可用
- 构造调用参数（base_token、table_id、记录定位条件、待写字段）
- 解析返回记录，按本技能规则使用与迁移状态

被调用方技能（lark-base）负责：
- 飞书多维表格的鉴权、读写、限频、错误码
- 表格记录与字段定义的全部底层操作

本技能明确不执行以下操作：
- 不直接调用任何飞书开放接口
- 不存储、不读取、不经手任何飞书凭证（token/app_id/secret）
- 不代替 lark-base 完成其领域内的其他表格操作（建表、改表结构、视图管理等）；唯一例外：初始化期经用户同意后为「选题状态」补充"已淘汰"选项（已于 2026-09-09 完成，此后不再触碰表结构）

## 二、依赖检测

检测方式：尝试一次只读调用（按编号定位一条记录）探测可用性；用户身份（user）优先，user 不可用时按 lark-base 指引走 bot 身份。

- 可用 → 继续主流程
- 不可用 → 提醒用户检查 lark-base 安装与授权，同时启用备用通道：请用户把选题行内容粘贴给本技能，分析照常进行；状态迁移与回填暂停，待人审通过后由用户手动改状态，本技能输出"待迁移字段清单"

## 三、输入参数

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|---|---|---|---|---|
| base_token | string | 是 | 多维表格分享 token | 目标题库；由用户在初始化时提供，本技能不写死 |
| table_id | string | 是 | tbl 前缀的表 ID 或表名 | 选题表 |
| locate_by | enum | 是 | 选题编号 / 选题标题 | 记录定位方式 |
| locate_value | string | 是 | 编号如 T-2026-001，或标题全文 | 定位值 |
| read_fields | array[string] | 否 | 字段名列表 | 缺省读全字段 |
| write_fields | map | 否 | 字段名→值 | 仅 N9 使用；仅可写 pool-field-map.md A 区字段 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|---|---|---|---|
| status | string | 始终 | success / error |
| record | map | success | 记录全部字段值；select/checkbox 按 lark-base 返回的原样结构 |
| record_id | string | success | 记录 ID，写回时用 |
| matched_count | int | success | 定位命中数；≠1 时按异常处理 |
| error_msg | string | error | 用户可理解的错误描述 |

## 五、异常处理

| 异常情况 | 处理方式 |
|---|---|
| lark-base 不可用/未授权 | 备用通道：用户粘贴选题行；迁移改输出"待迁移字段清单"由用户手改 |
| status = error | 展示 error_msg；读失败终止本次分析，写失败暂停迁移并报告（**禁止自动重试**） |
| matched_count = 0 | 提示编号/标题未命中，请用户确认后重新定位；禁止模糊猜测匹配 |
| matched_count > 1 | 列出命中标题请用户指认，禁止取第一条 |
| 返回缺少 read_fields 中字段 | 该字段按「无记录」处理并在分析卡标注，禁止编造 |
