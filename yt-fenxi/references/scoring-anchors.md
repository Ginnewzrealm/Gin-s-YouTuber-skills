# 评分锚点与判定细则

> 本文件是 N3 机评、N4 C 闸门、N5 核验、N6 穷举四个节点的判定标尺。
> 原则：所有标准可外化核验，不含"感觉""经验"类隐性词（用户拍板：必须客观而非主观）。
> vN6.0（2026-09-10）：评分轴换为**拆局价值四维**（频道定位升级为买方视角商业极境拆局纪录片）；
> 原流量四维（Demand/Conflict/Outlier/Archive）降为参考层——仍评估、附卡，但不进总分、不进闸门。

## 一、机评主评分轴（N3）：拆局价值四维

输入：yt-ziliao 资料包 + manifest（N2 已过，原料在场）。流程：按 挖掘手册-v2 三层×五维清点证据 → 四维打分。

**加权公式**：总分 = 非共识强度×30% + 齿轮可还原度×30% + 决策考古浓度×25% + 关卡流潜力×15%（满分 100）

| 维度 | 锚点 80-100 | 锚点 50-79 | 锚点 <50 |
|---|---|---|---|
| 非共识强度（30%） | 阻力场料厚：做空报告/主流媒体嘲讽/内部反对/对手打压 ≥3 类且有实据 | 有 1-2 类阻力场实据 | 几乎无阻力记录，全网一边倒好评 |
| 齿轮可还原度（30%） | PMF 咬合点/单元经济能挖到具体数字（CAC/LTV 拐点、成本结构、波峰月份数据、跳号订单级） | 有定性描述但数字不全 | 只有结果叙事（"突然火了"），无过程数字 |
| 决策考古浓度（25%） | 三方对照信源全部可得（创始人/离职者或对手/投资人，各有实料） | 两方可得 | 只有创始人官方叙事一方 |
| 关卡流潜力（15%） | 一生能拆出 ≥4 关（足够 25 分钟关卡流叙事） | 3 关 | <3 关（撑不起长片） |

**参考层（原流量四维，不进总分不进闸门）**：Demand/Conflict/Outlier/Archive 仍按原锚点评估（下表），附在分析卡 §二 下半部，供 N6 空白度（对标池点名）与人工参考。

| 维度 | 锚点 80-100 | 锚点 50-79 | 锚点 <50 |
|---|---|---|---|
| Conflict 冲突 | 存在法律/制度层面冲突或重大利益反转 | 明确争议或质疑、重大变化、出乎意料的结果 | 平淡叙事、无对抗无反转 |
| Archive 资料厚度 | 工商/司法/深度报道 ≥3 项可采 | 2 项可采 | <2 项 |
| Demand 需求 | 近 90 天同类爆款 ≥3 且播放量级高 | 有同类爆款但少 | 无同类爆款记录 |
| Outlier 离群 | 对标池无人讲过或角度显著不同 | 有人讲过但留有空隙 | 已被讲透 |

**档位**（Q1 拍板，原机制不变）：
- **重档（默认）**：参考层四维调 YouTube Data API 精算对标数据；主评分轴仍按资料包打分。
- **轻档（降级）**：API 限流/不可用时，参考层四维改 WebSearch 定性判断 + 置信度标注（高/中/低）。分析卡必须标注"本次机评为轻档"。
- 机评不可跳过——C 闸门④空方压力测试依赖主评分轴非共识强度的输出。

## 二、C 闸门四硬条件（N4，一票否决，vN6.0 改造）

| 条件 | 通过线 | 核验方式 |
|---|---|---|
| ① 三方对照可得（原"硬核信源≥2"改造） | 创始人视角 + 至少一方反方视角（离职者/对手/投资人）均有实料可得 | 对资料包按视角清点（归 挖掘手册-v2 三方对照），不数条数看视角覆盖 |
| ② 合规 | 无敏感赛道风险（政治敏感/未决诉讼指向个人/隐私侵权） | 关键词预警 + 资料包事实核查 |
| ③ 获得感 | ≥40 分 ⇔ 反常识点 ≥1 个 | 穷举"原本以为…结果…"点数（常识错位法见 N6 §4.4） |
| ④ 空方压力测试（新增） | 产出 ≥1 条具体 Kill_Thesis 草案："若 3 年内市值蒸发 50% 的单点崩溃原因"——有触发条件、有崩溃路径、有空方证据包来源支撑 | 基于资料包维度五 a 空方证据包起草；空泛质疑（"竞争加剧""行业不景气"类无实据）= 不通过 |

- 逐项 ✓/✗ 呈现（Q6 拍板），四维分小字附后。
- 任一 ✗ → 不出分析卡，建议不做 + 理由，状态迁已淘汰。
- Kill_Thesis 是"立项压力测试"不是"唱衰结论"：过得了这关才说明选题有真实张力；推导只到草案级，展开归脚本阶段叙事。
- **不豁免**（Q5）：时效热点（🔥热点标签）一视同仁。热点新主体（如 China GT 换运营公司）走 N1 选题精化，素材达标即可立项。

## 三、事实核验三分（N5，独立 pass）

五分类提取：事实断言 / 统计数字 / 归属引语 / 定义 / 历史声明。

| 分类 | 标准 | 呈现 |
|---|---|---|
| 已证实 | ≥2 个独立信源互证 | 卡内正常引用 |
| 待验证 | SIFT 后仍冲突（Stop→Investigate→Find better→Trace） | **冲突证据保持可见**，卡内标"存疑" |
| 观点 | 无法证伪的立场/预测 | 标注归属方（谁说的） |

- 无源主张 → 盲区清单 + 补采建议（写进分析卡「事实核验」节）。
- 待验证项进脚本阶段前必须有人工或新一轮核验消化。

## 四、切入点穷举四维度 + 四维视角层（N6，2026-09-09 深度化升级）

### 4.1 四维视角层穷举清单（覆盖检查表）

| 视角层 | 覆盖什么 | 空缺时的写法 |
|---|---|---|
| ① 当下反应层 | 事故当下 / 舆论反馈 / 各方回应 | —— |
| ② 历史脉络层 | 主体发展史 / 创办人决策史 / 关键转折节点 | "主体成立不足 X 年，无史可考"（须属实） |
| ③ 主体架构层 | 股权结构 / 商业模型 / 组织关系 | "股权结构未公开披露" |
| ④ 行业格局层 | 同类对比 / 国际对标 / 格局参照 / 监管环境 | "无同类可比赛事/公司" |

规则：每层 ≥1 角度，总计 5-8 个；空缺必须写原因，禁止编造。

### 4.2 四维度加权评分

综合分 = 空白度×30% + 凭证密度×25% + 反常识强度×25% + **深度揭示力×20%**（各 0-100）

| 维度 | 量法 |
|---|---|
| 空白度 | 对标池逐频道点名：谁讲过、谁没讲（"没人讲过"必须列查证范围） |
| 凭证密度 | 资料包中该角度可用的硬事实条数（数字/文件/时间线节点） |
| 反常识强度 | 该角度能成立的"原本以为…结果…"点数 |
| **深度揭示力（潜力分）** | **不看资料包厚薄，看角度的问题设计**：这个角度做透了，能否揭示主体的基因与"怎么走到今天"（起源/文化/团队/创始人/护城河/失败病根）？80-100=能讲清主体来龙去脉；50-79=能讲部分脉络；<50=只回答"主体是谁/发生了什么"（空壳型角度，China GT 94 分空壳链判例即此类） |

> 深度揭示力评潜力不评存量：资料少但问题设计深的角度不该被埋没；资料厚但只能答"是谁"的角度必须现形。
> 原料依赖：深度揭示力的实际发挥受 yt-ziliao D7 历史脉络覆盖度支撑；D7<40 时本维度得分旁标注"原料不足"。

### 4.3 分桶与标签

- **分桶保留功能分法**：Quick Wins（高分+低投入）/ Strategic Builds（高分+需补采）/ Long-term（有价值但条件未熟）。
- **每个角度加"视角层"标签**（①当下/②历史/③主体/④格局）——视角层是穷尽分类，桶是优先级排序，两轴分离，禁止合并。

### 4.4 切入瞬间穷举（N6 第 5 维，vN6.0 新增，来源：非虚构商业叙事切入点提取系统）

角度穷举回答"讲什么"，切入瞬间穷举回答"**第一帧从哪个物理切片炸开**"。拆局类选题在角度穷举后必做：

**步骤 1 —— 三锚点提取**：消费 yt-ziliao 报告 §5.4 候选锚点清单，并在资料包全文刻意检索三类物理锚点（清单不够就补挖）：
- **物件锚点**：被废弃的图纸/古怪的零件/不合时宜的包装盒（脑白金空盒、扔进鱼缸的 iPod 原型）
- **数字锚点**：荒谬 ROI/倒挂成本结构/跳号订单数/两极资金对比（负债 2.5 亿 vs 仅剩 50 万借款）
- **对话锚点**：密室决策中孤立无援或力排众议的一句原话（CFO 指出财务漏洞被当场解雇）

**步骤 2 —— Nieman 4C 合格检查**（每个候选必过，缺一不可；任一项不过即淘汰并记原因）：
- [ ] Concrete 物理具象：能落在具体房间/桌子/时间点/物件上？（拒绝"1998 年经济大潮"级抽象）
- [ ] Conflict 内在冲突：主角面临极度信息不对称/质疑/阻力？
- [ ] Consequence 重大后果：结局直接决定商业版图生死？
- [ ] Core Theme 母题隐喻：是整个公司命运的"微缩盆景"？

**步骤 3 —— 时机矩阵标注 + 人选**：每个通过 4C 的候选标注切入时机类型——

| 时机类型 | 悬念 | 硬核度 | 说明 |
|---|---|---|---|
| A 濒死危机 Crisis | ★★★★★ | ★★★ | 资金链断裂前夜/灾难瞬间（China GT 爆燃）；劣势：需大量回溯 |
| B 杠杆扣动 Pivot/MVP | ★★★★ | ★★★★★ | **买方视角最推荐**：数据突然爆表的异常时刻/差异化爆破点（美的 U 型空调） |
| C 灵感诞生 Genesis | ★★ | ★★ | 除非灵感极荒谬，避免从此切入 |
| D 巅峰转衰 Peak | ★★★ | ★★★★ | 奢华巅峰+隐秘不祥之兆（WeWork 车里 15 分钟敲定 44 亿） |

- **常识错位法**辅助产候选：列大众第一层共识 → 找绝对相悖的具体事实 → "你以为 X，但 Y"。
- 推荐优先级 B > A > D > C（买方视角），**最终人选 = N8 人审拍板**，本层只产候选+标注。

**穷举纪律**：候选 ≥2 个通过 4C 才够人审挑选；全部 4C 不过 → 如实写"本期无合格切入瞬间"并建议补采或不做，禁止硬凑。

**穷举纪律**：5-8 个角度，少于 5 个说明不充分继续挖；每个角度必须附差异点/优势/劣势/视角层各一行，只给名字不给论据的角度无效。
